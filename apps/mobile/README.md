# IELTS Passport Mobile

Capacitor wrapper for Android and iOS. The web assets are copied from `../../site`.

```bash
pnpm install
pnpm sync
```

Android: `pnpm add:android` then open `android/` in Android Studio, or run `./gradlew assembleDebug` in CI.

iOS: `pnpm add:ios` then open `ios/App/App.xcworkspace` on macOS with Xcode. A real IPA requires an Apple Developer certificate and provisioning profile.
