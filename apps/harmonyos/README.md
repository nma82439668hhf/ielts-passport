# IELTS Passport HarmonyOS

This is a HarmonyOS Stage-model WebView shell for the IELTS Passport website.

1. Install DevEco Studio 5.x and the HarmonyOS SDK.
2. Open this `harmonyos` directory as a project.
3. Configure automatic signing with your Huawei developer account.
4. Build `Build > Build Hap(s)/APP(s)`.

The WebView loads `https://nma82439668hhf.github.io/ielts-passport/`, so website updates are available without rebuilding the HAP. A signed HAP/APP is required before installation on a HarmonyOS device.
